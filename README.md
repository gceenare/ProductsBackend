# ProductsBackend
Java backend service managing product APIs and persistence.

About

ProductsBackend provides REST APIs for product management including listing, creation, and updates, and includes example database configuration.

Features

- Product CRUD endpoints
- Database migrations

Tech Stack

- Java
- Spring Boot

Quick start

```bash
# clone
git clone https://github.com/gceenare/ProductsBackend.git
cd ProductsBackend
# build and run
```
